01 // ABSTRACT

この論文が主張していること

WavePhaseNet は周波数で分解した意味表現を、QuantumPhaseNet はゲージ共変な位相接続を、 ModularPhaseNet は有限巡回群の位相チャネルとサイクルホロノミーを、通常の Transformer で計算できる形にした。 これらは意味の組織化の互いに補い合う側面を記述するが、観測された二者間の関係の集まりを、 大域的に一貫した向き・局所的な合成のまわりの循環・より大きな埋まっていないサイクルを回り続ける循環、 の3つに分けることは、それだけではできない。

HodgePhaseNet は意味の遷移を、有限の向き付き単体複体の上の反対称な実数値1-コチェイン \(\Omega\) として表す。 頂点–辺の接続行列 \(B_1\) と辺–面の接続行列 \(B_2\) を使うと、どんな \(\Omega\) も \(\Omega = B_1^{\top}\Phi + B_2\Psi + H\)（ただし \(B_1H=0,\ B_2^{\top}H=0\)）と一意に直交分解される。 ポテンシャル \(\Phi,\Psi\) が一意でなくても、3つの成分の場は一意である。 論文は明示的な射影子、疎な実装、可積分性とゲージに関する結果、検算済みの数値例、そして作り直した Attention インターフェースを与える。

Attention のバイアスは許可された順序付き query–key 対の上で定義され、辺の向きの選び方に依存せず、 デコーダでは複体を見えているプレフィックスだけから作ることで因果的な情報境界を守る。 Attention 出力のゲージ不変性は、不変な特徴量または補償された特徴量を使う場合に限って成り立つ。 頂点埋め込みの単純な差には局所循環成分も調和成分もないため、本物の関係エンコーダが不可欠である。 局所循環はそれだけで矛盾を意味せず、調和成分はそれだけで知識の欠落を意味しない。 こうした解釈や事実誤りの低減は、統制された実験で確かめる必要がある。 本稿は数学とアーキテクチャの提案であり、自然言語での性能結果は報告していない。

G

勾配成分（exact）

頂点ポテンシャルの差 \(B_1^{\top}\Phi\) で説明できる部分。全体として一貫した「向き」や上下関係を表しうる。ただし一貫した誤りもここに入る

C

局所循環成分（coexact）

宣言した三角形の面の境界 \(B_2\Psi\) で説明できる回り込み。推移律の破れの候補にもなるが、正当な相互定義でも生じる

H

調和成分（harmonic）

どの頂点にも溜まらず、どの面でも回らないのに、埋まっていない大きなサイクルを回り続ける流れ。裏付けのない推論ループの候補にも、意図的な話題の回帰にもなる

02 // FROM THREE PAPERS

前3作から「辺の場」へ

通常の Transformer は query と key の類似度を softmax で混ぜるだけで、 「共通のポテンシャルから決まる向き」「局所的な三者の回り込み」「どの局所面にも還元できないサイクル」を明示的には区別しない。 階層・推論の連鎖・複数経路で支えられた主張を扱うとき、この区別が効いてくる。

前作与えるものそれだけでは言えないこと
WavePhaseNet系列方向の DFT によるスケールの特徴量（帯域エネルギー・再構成）帯域と意味役割の対応は経験的解釈にとどまる
QuantumPhaseNet局所位相の比較規則（共変な接続・共変位相残差）辺の場全体のうち、どこがポテンシャル差で、どこが面の境界で、どこが大域サイクルかは言わない
ModularPhaseNet有限群による厳密な整合性検査（サイクルホロノミー）「整合か否か」は答えるが、辺のエネルギーを勾配・局所・大域へ実数で直交に配分しない

HodgePhaseNet はこれらを関係エンコーダの入力として使い、その出力である実数の反対称な辺の場が、 宣言された頂点・辺・合成可能な面の上でどう分解されるかを問う。「境界の境界はゼロ」という恒等式のおかげで、 この問いは初等的な有限次元の Hodge 問題になる。

解説者注：「調和」の意味が WavePhaseNet と違う
  • WavePhaseNet の調和射影は、頂点（0-コチェイン）の Laplacian の核への射影で、「最も整合した貼り合わせ成分」を取り出す操作だった。
  • 本作の調和成分 \(H\) は辺（1-コチェイン）の場で、埋まっていないサイクルを回る循環を表す。同じ「harmonic」でも指す対象が違う。
  • 論文自身も「調和の考え方を PhaseNet 系列に初めて持ち込んだとは主張しない」と明記し、分解の対象を辺の関係場へ移した点を新しさとしている。
03 // SEMANTIC COMPLEX

意味の単体複体と離散作用素

頂点・辺・面

\(K=(V,E,F)\) を、頂点 \(n_0\) 個・辺 \(n_1\) 本・三角形の面 \(n_2\) 枚からなる有限の2次元単体複体とする。 頂点はトークン・文・主張・エンティティ・概念のいずれでもよく、粒度は層ごとに固定する。 辺は合成可能な関係の候補、面は「3本の境界の関係が局所的に合成可能」と明示的なタスク規則で判断されたことを意味する。

面を全部外すと

局所循環の部分空間 \(\mathrm{im}\,B_2\) が消える。三角形の回り込みはすべて調和成分か勾配成分に押し出される

三角形を全部埋めると

アプリケーションが残したかった大域サイクルまで消えうる。どの三角形を面にするかは実質的な仮定であり、アブレーションが必要

接続行列と鎖条件

各辺・各面に任意の向きを決める。\(B_1\in\mathbb{R}^{n_0\times n_1}\) の列 \(e: i\to j\) は \(i\) に \(-1\)、\(j\) に \(+1\) を持ち、 \(B_2\in\mathbb{R}^{n_1\times n_2}\) は各面の向き付き境界を記録する。

鎖条件・余境界・1-Hodge Laplacian \[ B_1B_2=0 \] \[ d_0=B_1^{\top},\quad d_1=B_2^{\top},\quad \delta_1=B_1,\quad \delta_2=B_2,\quad d_1d_0=0 \] \[ L_1=B_1^{\top}B_1+B_2B_2^{\top},\qquad \langle\Omega,L_1\Omega\rangle=\|B_1\Omega\|_F^2+\|B_2^{\top}\Omega\|_F^2 \]

\(B_2^{\top}B_1^{\top}\Phi=0\)、つまりポテンシャル差は埋めた面のまわりで必ず和がゼロになる。 Laplacian のエネルギーの2項は、頂点での湧き出し（発散）と、宣言した面のまわりの循環を測る。 どちらも代数的な量であって、事実の正しさのラベルではない。向きの選び方は座標の選択にすぎず、 関係の真偽や時間的な向きを予測したものではない。

非自明な辺の場をつくる

層 \(\ell\) の頂点状態 \(x_i^{(\ell)}\) に対し、関係エンコーダは辺の両方向を、向きを反転したメタデータとともに評価し、反対称化する。

反対称な関係場 \[ R_{ij}=R_\vartheta\bigl(x_i,x_j,r_{ij},c_{ij},f^{W}_{ij},f^{Q}_{ij},f^{M}_{ij},f^{E}_{ij}\bigr),\qquad \Omega_{i\to j}=\frac{R_{ij}-R_{ji}}{2} \]

これで \(\Omega_{j\to i}=-\Omega_{i\to j}\) が保証される。 \(f^W\) は帯域エネルギーや再構成（Wave）、\(f^Q\) は共変位相残差と実数の接続（Quantum）、 \(f^M\) は巡回群の関係と近傍のホロノミー（Modular）、\(f^E\) は検索された根拠と関係タイプ。いずれも任意の、測定可能な入力である。 ゲージに関する結果が必要なときは、接続チャネルを \(\Omega=a+\tilde R\)（\(\tilde R\) はゲージ不変・向き同変）と置くことで \(\Omega'=\Omega+B_1^{\top}\chi\) という変換則が成り立つ。制約のないエンコーダには、この変換則は自動的には備わらない。

PROPOSITION 1  単純な差は縮退する

\(X\in C^0(K;\mathbb{R}^r)\) について \(\Omega=B_1^{\top}X\) とすると、局所循環成分と調和成分への射影はどちらもゼロになる。 \(\Omega\in\mathrm{im}\,B_1^{\top}\) は鎖条件により \(\mathrm{im}\,B_2\) と直交し、定義により \(\ker L_1\) とも直交するからである。

これは設計上の重い制約である。頂点埋め込みの差だけで作った場は、下流の Hodge 層をどう調整しても循環を表せない。 ModularPhaseNet で「接続を頂点位相の比から作ると、どのサイクル積も恒等的に1になる」とした落とし穴の、実数版にあたる。

04 // HODGE DECOMPOSITION

直交分解と計算できる射影子

THEOREM 1  離散意味 Hodge 分解

\(K\) を固定すると、任意の \(\Omega\in C^1(K;\mathbb{R}^r)\) は成分場への一意な直交分解を持つ。

3項分解 \[ \Omega=G+C+H=B_1^{\top}\Phi+B_2\Psi+H,\qquad B_1H=0,\quad B_2^{\top}H=0 \]

ポテンシャル \(\Phi,\Psi\) は一意とは限らないが、\(G,C,H\) は一意。 証明は、\(\langle B_1^{\top}\Phi,B_2\Psi\rangle_F=\mathrm{tr}(\Phi^{\top}B_1B_2\Psi)=0\) と、 \(\mathrm{im}\,B_1^{\top}\oplus\mathrm{im}\,B_2\) の直交補空間が \(\ker B_1\cap\ker B_2^{\top}=\ker L_1\) であることによる。

射影子と疎な解法

Moore–Penrose 擬似逆による射影子 \[ P_G=B_1^{\top}(B_1B_1^{\top})^{\dagger}B_1,\qquad P_C=B_2(B_2^{\top}B_2)^{\dagger}B_2^{\top},\qquad P_H=I-P_G-P_C \]

大きな疎な複体では密な射影子を作らず、列ごとに次の2つの正規方程式を解く。

実装で解くもの \[ (B_1B_1^{\top})\Phi=B_1\Omega,\qquad (B_2^{\top}B_2)\Psi=B_2^{\top}\Omega,\qquad H=\Omega-B_1^{\top}\Phi-B_2\Psi \]

\(\Phi\) は連結成分ごとに平均をゼロにするか1頂点を固定し、面の系の核には最小ノルム解で対処する。 前処理付き共役勾配法・LSQR・疎な分解などが使えるが、許容誤差は記録しなければならず、近似解を厳密な直交射影と呼んではならない。

エネルギー・トポロジー・可積分性

エネルギーの分配 \[ \|\Omega\|_F^2=\|G\|_F^2+\|C\|_F^2+\|H\|_F^2,\qquad \rho_s=\frac{\|s\|_F^2}{\|\Omega\|_F^2},\qquad \sum_{s\in\{G,C,H\}}\rho_s=1 \]

実係数では \(\dim\ker L_1=\beta_1(K)\)（第1 Betti 数）。調和の部分空間はトポロジーが許せば存在するが、 ある場がそこへの射影をゼロとして持つこともある。\(\beta_1>0\) も \(\|H\|>0\) も、それだけでは知識の欠落を証明しない。

THEOREM 2  連結な \(K\) の上で、\(\Omega=B_1^{\top}\Phi\)（\(\Phi\) は定数差を除いて一意）となるのは \(C=H=0\) のときに限る。 局所条件 \(B_2^{\top}\Omega=0\) は局所循環成分を消すが \(H\) は消さないので、 埋まっていないサイクルがあるかぎり、局所的に整合していても大域ポテンシャルの存在は言えない。

確信度による重み付け

正定値の対角行列 \(W_k\) で内積 \(\langle u,v\rangle_{W_k}=u^{\top}W_kv\) を入れると、重み付きの随伴と Laplacian は次のとおり。

重み付き版 \[ \delta_1^{W}=W_0^{-1}B_1W_1,\qquad \delta_2^{W}=W_1^{-1}B_2W_2,\qquad L_1^{W}=B_1^{\top}W_0^{-1}B_1W_1+W_1^{-1}B_2W_2B_2^{\top} \]

\(C^1=\mathrm{im}\,d_0\oplus_{W_1}\mathrm{im}\,\delta_2^{W}\oplus_{W_1}\ker L_1^{W}\)。 面の重みをちょうどゼロにすると階数が変わり \(\beta_1\) が変わりうるが、小さな正の重みは計量を変えるだけでコホモロジーの次元は変えない。 トポロジーを固定したいなら、微分中も候補面の重みを厳密に正に保つ。

05 // ATTENTION

分解結果を Attention に戻す

関係複体の組み立て

選んだ層とヘッドで、系列上の隣接・型の合う知識／根拠リンク・ベースの attention スコアで選ばれた少数の対から、 上限付きの候補辺集合を作る。面は3辺がそろい、明示された合成規則が認めるときだけ加える。 この規則は、評価用に伏せた正解のラベルではなく、入力側で使える情報だけで決めなければならない。 複体はヘッド間で共有してよいが、\(\Omega^{(\ell,h)}\) とその分解はヘッドごと。

面が1枚もなければ \(C=0\)、複体が木なら \(C\) も \(H\) もゼロになる。 この結果を「矛盾が検出されなかった」と読んではならず、そのまま報告する。

辺の特徴量と補償勾配

辺 \(e\) の局所特徴として、向き付きの局所循環値・調和値 \((C_e,H_e)\) と、その向きに依存しないノルムを使う。 面 \(f\) の符号付き局所循環 \(\kappa_f=(B_2^{\top}\Omega)_f\) を辺に集約し、成分の比も特徴にする。

面の集約・成分比・補償勾配 \[ t_e=\frac{\sum_{f:\,e\subset\partial f}(B_2)_{ef}\,\kappa_f}{\max\{1,\sum_f|(B_2)_{ef}|\}},\qquad \sigma_s=\frac{\|s\|_F^2}{\|C\|_F^2+\|H\|_F^2+\varepsilon}\quad(s\in\{C,H\}) \] \[ D_e=G_e-(B_1^{\top}\theta)_e \]

生の勾配 \(G=P_G\Omega\) は接続のゲージ変換で変わる。トークン位相 \(\theta\) が一貫した実数チャートで得られ \(\theta'=\theta+\chi\) と変換するなら、 補償勾配 \(D\) はゲージ不変になる。どちらも無いなら、ゲージ不変をうたうバイアスから \(G\) を外す。 \(\|G_e\|\) や \(\rho_G\) を使ってもこの問題は解決しない（それらもゲージで変わる）。

順序付き query–key 対へのバイアス

query \(i\) と key \(j\) に辺 \(e(i,j)\) があるとき、保存されている向きが \(i\to j\) なら \(s_{ij}=+1\)、そうでなければ \(-1\)。 符号付きの量には必ず \(s_{ij}\) を掛けてから使う。

順序付き対の特徴とバイアス \[ u_{ij}=\bigl[s_{ij}C_e;\ s_{ij}H_e;\ s_{ij}D_e;\ s_{ij}t_e;\ \|C_e\|_2;\ \|H_e\|_2;\ \sigma_C;\ \sigma_H;\ f^{E}_{ij};\ r_{ij}\bigr] \] \[ b^{H}_{ij}=\begin{cases}\gamma_h\tanh\bigl(f_{\eta,h}(u_{ij})\bigr), & e(i,j)\in E\\ 0, & e(i,j)\notin E\end{cases}\qquad z^{H}_{ij}=\frac{q_i^{\top}k_j}{\sqrt{d_k}}+b^{H}_{ij}+m_{ij} \] \[ \alpha_{ij}=\frac{\exp z^{H}_{ij}}{\sum_{t\in\mathcal{A}_i}\exp z^{H}_{it}},\qquad y_i=\sum_{j\in\mathcal{A}_i}\alpha_{ij}v_j \]

自己対は \(b^H_{ii}=0\)。\(\gamma_h=0\) で元の Attention 層に厳密に戻る。 Hodge の辺集合は選ばれた対にバイアスを与えるだけで、Transformer の密な許可パターンを置き換える必要はない（マスクまで疎にするなら、それは別の介入として比較する）。 バイアスの符号はタスクの根拠から学習され、正の回転も調和の大きさも、普遍的に負の意味を持つわけではない。

PROP 2 向きに依存しない

辺の向きを反転し、接続行列と辺の場を整合的に変換しても、すべての順序対のバイアスは変わらない。 符号行列 \(S_1,S_2\) で \(B_1'=B_1S_1,\ B_2'=S_1B_2S_2,\ \Omega'=S_1\Omega\) とすると \(G,C,H\) も \(S_1\) 倍になり、\(s_{ij}\) の反転と打ち消し合う。

PROP 3 条件付きゲージ不変性

\(\Omega'=\Omega+B_1^{\top}\chi,\ \theta'=\theta+\chi\) で、それ以外の入力とベースの logit がゲージ不変なら、特徴・バイアス・出力 \(y_i\) は不変。 直交性から \(P_C\Omega'=C,\ P_H\Omega'=H,\ P_G\Omega'=G+B_1^{\top}\chi\)、よって \(D'=D\)。 生の \(G\) を使うとこの主張は一般に成り立たない。

06 // CAUSALITY

自己回帰デコーダでの因果性

早い位置の query の Hodge 場を後のトークンも使って計算していたら、通常の因果マスクだけでは情報漏れを防げない。 位置 \(i\) の query には、見えているプレフィックス \(V_i=\{1,\dots,i\}\) から作った複体 \(K_i=(V_i,E_i,F_i)\) だけを使う。

プレフィックス複体 \[ E_i\subseteq\binom{V_i}{2},\qquad F_i\subseteq\Bigl\{(a,b,c)\in\binom{V_i}{3}:\partial(a,b,c)\subseteq E_i\Bigr\} \]

辺の端点・面・Wave 特徴・位相特徴・剰余特徴・関係ラベルのすべてが、そのプレフィックスから測定可能でなければならない。 teacher forcing の学習でも、位置 \(i\) の特徴は \(K_i\) のものを使い、系列全体で計算してマスクで隠したものを使ってはならない。 推論時はプレフィックスの解や検証済みの差分更新を再利用できる。

この要件は素朴な実装ではトークンごとの計算コストを押し上げる。 バッチ化・層の限定・主張レベルの粗いグラフ・近似的な差分更新を使う場合は、その近似誤差を実測で報告する。 双方向エンコーダは観測済み入力全体を使ってよく、cross-attention も観測済みのソースは全体を使えるが、生成中のターゲット側はプレフィックスに限る。

07 // LEARNING & COST

学習・リスク校正・計算量

学習目的と微分

目的関数の一例 \[ \mathcal{L}=\mathcal{L}_{\mathrm{task}}+\lambda_r\mathcal{L}_{\mathrm{relation}}+\lambda_q\mathcal{L}_{\mathrm{phase}} +\lambda_m\mathcal{L}_{\mathrm{holonomy}}+\lambda_c\mathcal{L}_{\mathrm{calibration}}+\lambda_b\mathcal{L}_{\mathrm{budget}} \]

厳密な Hodge 層では再構成・直交性の損失はソルバ誤差を除いてゼロになるので、学習信号ではなく診断値として扱う。 \(\|C\|\) や \(\|H\|\) に一律のペナルティを掛けると正当なサイクルまで消してしまうため、課さない。 収束した疎ソルバは陰関数微分で、固定回数の反復は展開して微分できる（許容誤差に依存する誤差が残る）。 離散的な top-\(k\) の所属判定には勾配は流れない。

高速な近似版は \(\hat\Phi,\hat\Psi,\hat H\) を学習して \(\hat G=B_1^{\top}\hat\Phi,\ \hat C=B_2\hat\Psi\) とし、厳密解に蒸留する。 \(\hat G\) と \(\hat C\) を接続行列を通してパラメータ化することが重要で、 「\(B_2^{\top}\hat G=0\) を課す」だけでは調和成分の混入を防げない。近似版には、測定誤差が裏付けるまで厳密分解の保証はない。

校正された誤りリスク

将来の「裏付けのない／誤った出力」ラベルに対し、見えているプレフィックスの特徴 (\(\rho_C\), \(\rho_H\), \(\|B_2^{\top}\Omega\|_F^2\), \(\mathrm{Hol}_q\), 根拠支持, 意味的不確実性) を集約し、 学習したスコア \(s_t\) を別の校正集合で確率 \(\hat p_t=\mathrm{Calibrate}(s_t)\) に写す。 温度スケーリングや等調回帰を Brier スコアと負の対数尤度で評価する。 conformal なリスク制御を使う場合、そのカバレッジ保証は別途明示する必要があり、生のスコアを校正済み確率に変えるものではない。 スコアはラベル付けした評価項目に対する経験的予測であって、真偽の神託ではない。

計算量：速くはならない

1つの複体あたり \[ O\bigl(T\,r\,[\mathrm{nnz}(B_1)+\mathrm{nnz}(B_2)]\bigr) \]

\(r\) はチャネル数、\(T\) は疎反復の回数。これに関係エンコード・複体構築・通常の Attention が加わる。 辺を \(O(kn_0)\) 本に絞れば Hodge の解法は疎のままだが、密な Attention の2乗コストはそのまま残る。 因果デコードで全 \(n_0\) 個のプレフィックスを個別に厳密に解けば、仕事量はさらに掛け算で増える。 漸近的な疎行列積の回数ではなく、実時間とピークメモリを報告することが求められている。

08 // FURTHER PROPERTIES

ゲージ・有限ホロノミー・安定性

ゲージ変換に対する射影の振る舞い \[ P_C(\Omega+B_1^{\top}\chi)=P_C\Omega,\qquad P_H(\Omega+B_1^{\top}\chi)=P_H\Omega,\qquad P_G(\Omega+B_1^{\top}\chi)=G+B_1^{\top}\chi \]

これは分解についての主張であり、学習したあらゆる意味特徴がゲージ不変だという保証ではない。 有限群のホロノミーは厳密な剰余チャネルに残しておく。主値の実数代表 \(\tilde a_e=\mathrm{wrap}_{(-1/2,1/2]}(a_e/q)\) を実数チャネルに入れることはできるが、 折り返しの境界をまたぐと不連続が生じ、使う実数リフトが変わる。 剰余ホロノミーと実数の成分エネルギーは、並べて評価する。

射影の非拡大性（固定した重みなし複体） \[ \|P_s(\Omega+\Delta)-P_s\Omega\|_F=\|P_s\Delta\|_F\le\|\Delta\|_F,\qquad s\in\{G,C,H\} \]

ただし \(E\) や \(F\) が変わる場合、ソルバを打ち切る場合、非線形モデルを学習する場合の安定性は意味しない。 Transformer 全体の大域 Lipschitz 連続性も主張しない。

THEOREM 3  凸結合による有界性

許可された logit が有限で、許可された key すべてで \(\|v_j\|_2\le B_V\) なら \(\|y_i\|_2\le B_V\)。 softmax の重みは非負で和が1なので、出力は値ベクトルの凸結合になる。 ModularPhaseNet の定理6と同じ論法で、学習の安定性や意味的妥当性の向上を主張するものではない。

09 // NUMERICAL EXAMPLE

検算済みの5頂点の例

頂点 \(V=\{1,2,3,4,5\}\)、向き付き辺 \(e_1:1\to2\), \(e_2:2\to3\), \(e_3:3\to1\), \(e_4:1\to4\), \(e_5:4\to5\), \(e_6:5\to1\)。 1つ目の三角形 \((1,2,3)\) だけを面として埋め、2つ目の三角形 \((1,4,5)\) は埋めない。

\(B_1B_2=0\)。グラフは連結で \(\mathrm{rank}\,B_1=4,\ \mathrm{rank}\,B_2=1\)、よって \(\beta_1=6-4-1=1\)。 \(\Phi=(0,1,2,-1,1)^{\top}\), \(\Psi=(0.5)\), \(H=(0,0,0,0.25,0.25,0.25)^{\top}\) と選ぶと次のようになる。

\(G=B_1^{\top}\Phi\)11−2−12−112
\(C=B_2\Psi\)0.50.50.50000.75
\(H\)0000.250.250.250.1875

10 // IMPLEMENTATION

実装手順と実行時チェック

1
入力をそろえる
見えている隠れ状態・関係メタデータ・根拠・Wave／Quantum／Modular の特徴チャネル。デコーダでは最初にすべてをプレフィックスに制限する
2
複体を作る
固定規則かベースの logit で頂点と上限付きの辺を選び、正準な向きを付け、合成規則が認める面だけを加える。\(B_1B_2=0\) を確認する
3
反対称な \(\Omega\) を作る
各辺の両方向で関係エンコーダを評価し反対称化。ゲージを主張するなら「接続＋不変残差」の形を強制する
4
2つの疎な系を解く
\(G,C,H\) を復元し、再構成・直交性・発散・面循環の残差を記録する。日常の推論で調和固有基底を全部求めることはしない
5
順序対のバイアスを計算
符号付きの辺の値に \(s_{ij}\) を掛け、特徴から有限のスカラーバイアスを作る。複体外の対と自己対はゼロ。元のマスクと softmax をそのまま適用
6
学習と校正
タスク目的・任意の関係／位相目的・資源ペナルティを計算。リスク校正器は、ベースモデルとスコアを決めた後に別の校正データで学習する

RUNTIME CHECKS

  • 辺と面の向きをランダムに反転し、3成分が同じ符号行列で変換され、エネルギー・logit・出力が変わらないこと
  • 接続に \(B_1^{\top}\chi\) を足し \(\theta\) も同じチャートで変換して、\(C,H,D\)・バイアス・出力が変わらないこと
  • 位置 \(i\) より後のトークンを編集しても、\(i\) までの logit と出力が変わらないこと
  • \(\gamma_h=0\) で元のマスク付き Attention に数値精度で一致すること

DEPLOYMENT VARIANTS

  • 収束まで解く疎ソルバ（精度の基準）
  • 反復回数を固定したソルバ（残差を報告）
  • 蒸留した近似ヘッド（蒸留・再構成・調和の各損失）
  • 近似による速さは実測すべきもので、分解の数学からは導かれない

提案を縮小・棄却する条件

CRITERIA THAT WOULD NARROW THE PROPOSAL
  • \(C,H\) が、関係と三角形の和をそろえた対照を超えて、正当なサイクルと問題のあるサイクルを見分けられない
  • 面の作り方を妥当な範囲で変えると結論が逆転する
  • 同じコストの関係 MLP で同じ改善が得られる
  • 向きやゲージのテストが、述べた仮定のもとで失敗する
  • 根拠と計算量をそろえると事実性の改善が消える
  • リスクスコアがエントロピーや根拠の対照より Brier スコア・選択的リスクを改善しない
  • レイテンシあたりの品質で、より安い verifier に勝てない
LIMIT
3成分の名前に意味は宿らない
勾配成分は一貫した向きを表しうるが、完全に一貫した誤った説明も勾配になる。局所循環は推移律の破れにも正当な相互定義にもなる。調和成分は裏付けのない推論ループにも意図的な長距離の回帰にもなる。意味は型付きの辺・面の規則・根拠・教師付きの結果に宿る。
LIMIT
分解は複体の作り方に依存する
頂点の粒度・辺の選択・面の埋め方で結果が変わる。動的なしきい値はトポロジーを不連続に変えうる。一意性の定理は固定した複体の上の場について成り立つもので、複体の選び方や言語の解釈には及ばない。
LIMIT
ゲージ・因果性・コスト
折り返した位相リフトはチャートに依存する。\(C,H\) がゲージ不変でも、生の勾配を使う Attention ブランチは不変にならない。厳密な因果デコードは多数の解法を要し、差分更新や学習した近似は測定可能な誤差を持ち込む。
LIMIT
高リスク領域と偏り
校正したリスクモデルは検証や回答保留の優先付けに役立ちうるが、出力には出典の確認と人の監督を残すべき。知識リンク・関係アノテーション・検索ソースの資源的・文化的な偏りは、言語と視点をまたいで測定すべきとされる。
13 // CONCLUSION

結論

HodgePhaseNet は、PhaseNet 系列の考え方が出会う具体的な数学の場所を与える。 スペクトルの特徴と、共変な位相関係や有限群の位相関係が反対称な辺の場を形づくり、 その勾配・局所循環・調和の射影が3種類の組織化を分ける。

この場を Transformer の Attention に戻すには、順序対の符号、因果デコードのための見えているプレフィックス、 ゲージを意識した勾配特徴の選択、そしてソルバとトポロジーの明示的な検査が要る。 代数と5頂点の例は厳密であり、意味的な利得とリスク校正は検証可能な仮説として残る。

次の経験的な一歩は、監査可能な疎な参照実装による合成データでの復元、 自然言語でそろえたベースラインとの比較、そして独立にラベル付けした正当・不当なサイクルでの評価である。
