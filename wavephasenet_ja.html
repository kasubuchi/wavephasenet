01 // ABSTRACT

この論文が主張していること

本論文は、Transformer / Attention メカニズムを測度論と周波数解析の観点から再定式化し、 ハルシネーションの構造的必然性を理論的に解明する。 中心的な指摘は、埋め込み空間がσ-加法族上の条件付き期待値として機能しており、 これが意味的真値集合と同型でないことが論理的一貫性の破綻の根本原因である、というものである。

この観察をもとに、DFT を用いて埋め込み空間内に意味的概念階層構造（SCHS）を明示的に構築する手法 WavePhaseNet を提案する。低周波成分がグローバルな意味・意図に、高周波成分がローカルな構文・表現に 対応することで、対角化された空間での精密な意味操作が可能となる。 さらに、重なり合う局所窓の被覆にグラフ構造を導入してコチェイン複体を定義し、 局所推論間の不整合をコバウンダリに基づく損失として定量化する。

本稿は理論的枠組みの提示であり、実験的検証は含まない。 提示されるのは数学的定式化、理論的導出、および今後検証すべき指標である。 この点は後述の「主張の地図」で明示的に区別する。

02 // MEASURE THEORY

自己回帰モデルを測度論で書き直す

σ-加法族としての文脈

自己回帰モデルは結合分布を条件付き確率の積として分解する。 過去のトークン列 \(X_{<t}\) が生成する情報集合（ボレル集合）はσ-加法族をなす。

分解とσ-加法族 \[ P(X_1,\ldots,X_N) = \prod_{t=1}^{N} P(X_t \mid X_{<t}), \qquad \mathcal{F}_t = \sigma(x_1,\ldots,x_t) \]

したがって可測空間 \((\Omega,\mathcal{F}_t,P)\) 上で定義された埋め込みベクトルは、 σ-加法族上のランダム変数として解釈できる。 モデル全体は条件付き期待値 \(E[\phi(X_{t+1})\mid\mathcal{F}_t]\) の逐次近似器である。

\(L^p\) 空間とノルム構造

埋め込み空間は内積空間を経由した（不完備な場合もある）ノルム空間として扱われる。 モデル全体は \(L^p(\Omega,\mathcal{F},P)\) に住み、そのノルムは確率分布の期待値を表すルベーグ積分に対応する。

\(L^p\) ノルム \[ \|f\|_p = \left(\int_\Omega |f(\omega)|^p \, dP(\omega)\right)^{1/p} \]

ここから決定的な帰結が出る。モデルの出力は点ごとの真値ではなく、確率分布上の平均的最適性である。 「もっともらしさの平均」を最大化しているのであって、個々の主張の真偽を最適化しているのではない。

Minkowski 不等式 \[ \|f+g\|_p \le \|f\|_p + \|g\|_p \]

この不等式により、異なる仮説 \(f_1, f_2\) を \(f = \alpha f_1 + (1-\alpha) f_2\) と線形結合できてしまう。 しかし空間の不完備性により、その結合が存在しない命題を指すことがある。 次節の定式化はここから始まる。

03 // THEORY

ハルシネーションの構造的必然性

定義

本稿はハルシネーションを次のように定義する。 「σ-加法族上で最適（高確率）であるが、現実世界の真値集合に属さない出力」。

幻覚の定義 \[ \text{真値集合}\ T \subset V^{*}, \qquad \text{モデル最適集合}\ \arg\min_f E\big[\ell(f(X),Y)\big], \qquad T \neq \arg\min L^p \]

この定義の要点は、幻覚をモデルの失敗ではなく、二つの集合のズレとして捉えるところにある。 モデルは自らの目的関数の上では正しく振る舞っている。ズレているのは目的関数の方である。

なぜ不可避なのか：非凸な真値集合 vs 凸な表現空間

真値集合は一般に非凸であり、線形結合について閉じていない。 一方 \(L^p\) 空間は線形かつ凸である。この構造的ミスマッチが本質的原因である。

TRUTH SET \(T\)

非凸。飛び地を持ち、二つの真な主張の中点が真とは限らない。 Čech 型の整合性（局所的な真理の貼り合わせ）を要求する構造。

EMBEDDING SPACE \(L^p\)

線形かつ凸。任意の二点の内分点が必ず存在する。 大数の法則による統計的平均化は「平均的にもっともらしい分布」しか与えない。

したがって LLM は多様で柔軟な文章生成には適するが、 厳密な論理的厳密性を要する推論過程には原理的に不向きである、と論文は結論する。 そしてこの弱点が致命的になる領域として、AIエージェントとエッジコンピューティングを名指ししている。

⚠ この主張の射程
  • 「不可避」とはこの定式化の下でという意味である。埋め込み空間を非凸な構造に作り替える別の道を否定するものではない（むしろ本稿はその方向を提案している）。
  • また、幻覚が構造的に生じることと、その頻度や深刻度は別問題である。本稿は前者を扱い、後者の定量化は行っていない。
04 // SCHS

なぜ意味的概念階層構造が必要か

解決の方向は「表現空間の側に意味の階層を作る」ことである。ではなぜ既存の手段では足りないのか。

既存手段限界
シソーラス・オントロジー・知識ネットワーク 埋め込み空間（σ-加法族空間）へ直接埋め込むことができない。外付けの構造にとどまる
RAG 外部への強い依存性と拡張性の低さ。検索結果の品質がそのまま出力品質の上限になる

05 // DFT

系列方向DFTと完全再構成

定義

トークン列長を \(N\)、埋め込み次元を \(d\)、埋め込み行列を \(X\in\mathbb{R}^{N\times d}\) とする。 系列方向にDFTを適用すると、各埋め込み次元について次を得る。

系列方向DFT \[ \hat{X}_k = \sum_{n=0}^{N-1} X_n \, e^{-2\pi i k n / N}, \qquad k = 0,\ldots,N-1 \]
振幅・位相分解 \[ \hat{X}_k = A_k \odot e^{i\Phi_k}, \qquad A_k = |\hat{X}_k| \in \mathbb{R}^d, \qquad \Phi_k = \angle\hat{X}_k \in \mathbb{R}^d \]

振幅 \(A_k\) は各帯域がどれだけ強く効いているかを、位相 \(\Phi_k\) は その成分が系列上のどこに寄るかを決める。 位相を捨てると位置情報が失われる — これが FNet との決定的な違いになる。

完全再構成と共役対称性

DFTは可逆であり、逆変換によって元の埋め込み行列を完全に復元できる。 論文は \(d=4, N=3\) の最小例で実際の数値を追い、完全再構成を確認している。

共役対称性 \[ \hat{X}_{N-k} = \overline{\hat{X}_k} \quad\Longrightarrow\quad \text{実数値での復元が保証される} \]

この対称性には実装上の意味がある。高周波成分は半分だけ学習すればよい。 残りは共役から自動的に決まるため、学習すべきパラメータが実質的に半減する。

提案モデルとの対応

最小例が示すのは、(i) 低周波を要約ベクトルとして固定し、(ii) 高周波の位相と振幅を条件付きで生成し、 (iii) 逆DFTで文を再構成する — という設計が数学的に整合し、完全再構成を許すということである。 DFT自体の健全性が確認できた上で、低周波（大域的意味）・中周波（多段階の中間意味）・高周波（局所的意味）の 同時行列表現による証明へ進む、というのが論文の構成である。

⚠ 帯域と意味の対応は仮定である
  • 「k=2 が否定・対比構造に対応する」という割り当ては、この数値例における解釈であって、一般に成り立つ法則として証明されたものではない。
  • 帯域と意味役割の対応は、実データでの検証を要する経験的仮説である。論文もこれを「後の数値例と完全再構成の証明によって支持される仮定」と位置づけている。

Transformer への統合

置き換えではなく差し込みである。各層 \(l\)・各ヘッド \(h\) について長さ \(w\) の短い窓を トークン軸に沿ってスライドさせ、DFT を適用する。 窓の低周波再構成 \(g^{(l)}_t\) を、自己注意の入力に残差として加算する。

残差としての意図注入 \[ \tilde{x}^{(l)}_t = x^{(l)}_t + \alpha^{(l)} g^{(l)}_t \]

\(\alpha^{(l)}\) は学習可能なスカラー（またはチャネルごとのスケーリングベクトル）である。 この補正表現が Query / Key / Value の入力として使われる。

08 // DIMENSIONALITY

24,576次元 → 3,000次元の理論的根拠

Zipf則と 1/f スペクトル

自然言語はZipf則に従い、自己相似構造を持つ。 その結果、埋め込み振幅のエネルギースペクトルは 1/f 型の減衰を示す。

エネルギースペクトル \[ E(f) \propto \frac{1}{f^{\alpha}}, \qquad \alpha \approx 1.1 \sim 1.4 \]

\(\alpha > 1\) となる理由として、構文制約の存在（文法は意味論より局所的である）と、 Transformer の LayerNorm / Attention が高周波を正則化することが挙げられる。

  • 累積エネルギー 82〜88% は 1/f モデルからの理論的導出であり、実際の GPT-4 埋め込みを解析した測定値ではない。

  • この主張は実測可能であり、既存モデルの埋め込みスペクトルを解析するだけで検証できる。本稿の主張のうち最も検証しやすい部分である。
09 // COHOMOLOGY

局所推論の整合性をどう測るか

ここまでで「大域的な意図を取り出す」道具は揃った。残るのは 局所の推論どうしが矛盾しないことをどう保証するかである。

スペクトルエントロピーと帯域選択

どこまでを「低周波」とするかは恣意的に決めない。スペクトル分布に対するエントロピー汎関数を定義し、 情報損失を最小化する帯域 \(\Omega\) を選ぶ。

帯域選択規準 \[ H(p) = -\sum_{n=1}^{T} p_n \log p_n, \qquad p^{(\Omega)}_n = \frac{E_n \mathbf{1}(n\in\Omega)}{\sum_{m\in\Omega} E_m} \] \[ \min_{\Omega} D_{KL}\big(p \,\|\, p^{(\Omega)}\big) \quad\text{または}\quad \sum_{n\in\Omega} E_n \ge \rho \sum_{n=1}^{T} E_n \]

つまり「エネルギー保存率 \(\rho\) を満たす最小の帯域」を選ぶ。 前節の累積エネルギー解析は、この規準を GPT-4 の次元に当てはめたものである。

大域意図ベクトル \(g\)

選ばれた低周波帯域から、逆DFT再構成によって大域意図埋め込みを定義する。 位置に依存しない意図を仮定する場合は帯域内の全周波数成分を平均する。

大域意図 \[ g = \frac{1}{|\Omega|}\sum_{n\in\Omega} \Re\big(\tilde{V}_{(:,n)}\big) \in \mathbb{R}^d, \qquad G = \mathrm{IDFT}\big(\tilde{V}_{(:,\Omega)}\big) \in \mathbb{R}^{d\times T} \]

位置依存の再構成を各トークン位置に対応させる場合は \(G\) を用いる。これが系列版の大域意図となる。

窓被覆・コチェイン・コバウンダリ

トークン集合を覆う重なり合う窓の族 \(\mathcal{U}=\{U_i\}\) を考える。 各窓に対して局所推論モジュールが切断表現 \(s_i \in \mathbb{R}^r\) を出力し、 \(s=(s_1,\ldots,s_N)\) が0-コチェインをなす。

コバウンダリ作用素 \[ \delta s = (B \otimes I_r)\, s, \qquad U_i \cap U_j \neq \emptyset \ \Longleftrightarrow\ (i,j)\in E \]

\(B\) は有向接続行列である。\(\delta s\) の大きさが、窓どうしの解釈の食い違いの総量にあたる。 これをゼロに近づけることが「意味の貼り合わせ」に相当する。

Hodge分解と調和射影

Laplacian の固有分解 \(L = U\Lambda U^{\top}\) において、 零固有値に対応する部分空間 \(\ker L\) が、 すべての窓に矛盾なく値を割り当てる調和0-コチェインに対応する。

グラフ Hodge 分解と調和射影 \[ \mathbb{R}^{mr} = \mathrm{im}(\delta^{\dagger}) \oplus \ker(L\otimes I_r) \oplus \mathrm{im}(\delta) \] \[ P_{\mathrm{harm}} = U_0 U_0^{\top}, \qquad s_{\mathrm{harm}} = P_{\ker(L\otimes I_r)}\, s \]

実装では零空間の基底 \(U_0\) を特異値分解または Lanczos 法で計算する。 重要な但し書きとして、この射影は高次コホモロジーに由来する真の障害を消さない。 それらは学習によって減らすべき不可避の意味的不整合として残る、と論文は明記している。

12 // LIMITS

限界と注意

実験的検証が存在しない

本稿には評価実験、ベンチマーク比較、アブレーション研究のいずれも含まれない。 提示されているのは数学的定式化と、検証すべき指標の一覧である。 したがって「幻覚がどの程度減るか」という問いには、現時点で答えられない。 これは欠陥ではなく本稿の設計である — 原因の定式化を先に置き、対策の実証を後続に委ねる構成になっている。

射影で消せない障害が残る

論文自身が明記するとおり、調和射影は高次コホモロジーに由来する真の障害を除去しない。 それらは学習によって減らすべき不可避の意味的不整合として残る。 すなわちこの枠組みは矛盾を「ゼロにする」ものではなく、「測って減らす」ものである。

低周波が正しさを保証しない

低周波成分は「文書全体で一貫して現れる成分」であって、「正しい成分」ではない。 長く反復される誤情報も低周波になり得る。 大域意図の抽出は、事実性の検証とは独立に評価される必要がある。 後続の QuantumPhaseNet ではこの点が明示的な注意事項として扱われている。

13 // CONCLUSION

結論

本論文はLLMのハルシネーションを、学習不足やデータ欠陥ではなく モデル自身の数学的構造から必然的に生じる現象として定式化し、 DFTベースのSCHSを埋め込み空間に導入することでその抑制の理論的枠組みを提示した。

Zipf則と1/fスペクトルに基づく累積エネルギー解析により、 24,576次元から3,000次元への削減が正当化されることが本提案の核心的貢献である。 WavePhaseNet は意味的流れを線形代数で厳密に記述することを可能とし、 次世代の推論指向型言語モデルへの道を開く。

残された課題は、(i) 実データでのスペクトル構造の確認、(ii) 次元削減後の性能評価、 (iii) λ・μ・η のアブレーションによる寄与の切り分け、(iv) 局所整合率の実測である。 これらの一部は後続の QuantumPhaseNet で着手されている。
