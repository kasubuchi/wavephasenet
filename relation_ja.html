02 // SHARED

3本を貫いている土台

舞台は2度変わりましたが、根っこの発想は一貫しています。

問題の立て方

幻覚は学習不足ではなく、表現空間の構造から生じる。だからデータではなく空間を作り直す。この診断と処方は3本に共通します。

周波数・位相と意味の対応

ゆっくり変化する成分が文書全体の意図、速く変化する成分が局所的な表現。3本目では「位相変化が小さい＝長波長＝上位概念」という形で引き継がれ、いずれも経験仮説として扱われています。

位相を捨てない

複素表現の位相を保持し、意味操作に使う点は共通です。3本目は位相を離散化しますが、捨ててはいません。目盛りに丸めたうえで、合成・逆元・相対位相を厳密に計算します。

Transformer を置き換えない

補正項と残差として差し込む設計。係数をゼロにすれば元のモデルに厳密に戻ります。3本目はさらに徹底しており、追加される量はすべて実数のスカラーバイアスなので、既存実装のカーネル改変が不要です。

証明と仮説を混ぜない

数学的に証明できることと、実データで反証されうることを分けて書く姿勢は2本目から明確になり、3本目では「証明済み5定理／経験仮説／避けた5主張／反証条件7項目」として、さらに整理されています。

内在的構造の重視（外部根拠との役割分担）

意味の階層を埋め込み空間の内側に作る方針は共通です。ただし外部知識の扱いは分かれます。1本目は RAG を「外部依存が強く拡張性に乏しい」と批判しますが、2本目以降は検索根拠を Attention の根拠項・リスクの根拠不足項として積極的に組み込みます。

04 // CORE

技術的に本質的な変更は3つ

表の項目は多いですが、3本を読み比べるうえで特に重要なのは次の3点です。 最初の2つが1本目→2本目、3つ目が2本目→3本目の移行にあたります。

① 位相を、座標から不変量へ（Wave → Quantum）

WAVEPHASENET

2語の噛み合いを位相角の差で測ります。 しかし \(\Phi_k\) は基底の取り方に依存する座標です。

\(\cos(\varphi_i - \varphi_j)\) という式は、暗黙に 「全ての語に共通の基準軸がある」と仮定してしまっています。

→
QUANTUMPHASENET

接続による平行移動を挟んでから内積をとります。 基準軸を決めなくても、2点間の整合性を比較できます。

局所ゲージ変換の下で値が変わらないことが、定理として示されています。

共変位相速度と共変整合性 \[ \Omega_\gamma(t) = \operatorname{Im}\big\langle \hat\psi,\, D_t\hat\psi \big\rangle, \qquad C^{\nabla}_{ij} = \operatorname{Re}\big\langle \hat\psi_i,\ P^{\nabla}_{j\to i}\hat\psi_j \big\rangle \]

代償もあります。平行移動は経路に依存するため、最短測地線か、文章順序に沿う経路か、 学習された参照経路か、いずれかを固定する必要が生じました。 前稿にはなかった選択肢であり、実装上の判断項目が1つ増えています。

② 直線から、任意のグラフへ（Wave → Quantum）

WAVEPHASENET

DFT は「トークンが等間隔に一列に並んでいる」ことを前提とします。

係り受け、共参照、検索根拠といった系列以外の関係は、 この枠組みでは扱えません。

→
QUANTUMPHASENET

グラフ Laplacian の低固有モードに置き換えることで、 任意の接続構造の上で同じ低周波抽出ができます。

辺集合には causal 近傍・k近傍・構文依存辺・共参照辺・検索根拠辺を混ぜられます。

文書は本来、一列に並んだトークン列ではなく参照関係のネットワークです。 この一般化はそのまま3本目にも引き継がれ、トークン・文・命題を頂点とする有向グラフとして再登場します。

③ 連続から、有限へ（Quantum → Modular）

QUANTUMPHASENET

位相は連続な複素振幅 \(\psi=Ae^{i\phi}u\) として表され、 スペクトル選択には QFT・位相推定・振幅増幅が使われます。

表現力は高いものの、複素演算が必要で、 整合性の判定は近似計算にならざるを得ません。

→
MODULARPHASENET

位相を \(q\) 個の目盛りに丸め、群要素 \(g^{a}\bmod p\) として保持します。 合成は群の乗算、相対位相は群の除算になります。

結果として整合性の判定が厳密な整数比較になり、 同じ入力からは必ず同じ判定が再現されます。

共変残差とサイクルホロノミー（有限群版） \[ r_{ij}=z_{i}^{-1}U_{ij}z_{j}\in G, \qquad W_{C}=\prod_{t=0}^{m-1}U_{i_{t}i_{t+1}}\bmod p \]

ここで重要なのは、この移行で表現力は増えていないことです。 論文自身が「冪剰余表現は指数剰余表現と同型であり、それ自体は新しい表現能力を生まない」と明記しています。 得られるのは表現力ではなく、厳密な合成・再現性・部分群への射影・チェックサムとしての検査可能性です。 代償は離散化誤差（小さい \(q\) でのエイリアシングとコード衝突）と、生成元の取り替えに対する座標依存性です。

⚠ 3本目が速くなるわけではない

整数演算に落ちたからといって、Attention 全体の計算量が改善するわけではありません。 密な attention の \(O(N^2 d)\) はそのまま残り、追加のペアバイアス項が \(H\ll d\) のとき低次に収まる、という主張に留まります。 3本目の価値は高速化ではなく、厳密さと検査可能性という帰納バイアスにあります。

05 // CONTINUITY

引き継がれたもの、引き継がれなかったもの

後続が前作を完全に包含しているわけではありません。3本を通して見ると、消えた主張、形を変えて戻ってきた主張、意図的に捨てられた主張があります。

① コホモロジーと Hodge 分解 — 形を変えて部分的に戻ってきた

1本目の中核だった「窓被覆・コチェイン・コバウンダリ・調和射影による意味の貼り合わせ」は、 2本目でほぼ姿を消し、局所の食い違いを測る役割は曲率と幾何リスクに置き換わりました。

3本目では、この系譜がサイクルホロノミーと離散可積分性として戻ってきます。 「すべてのサイクルで \(W_C=1\) ならば、大域的な意味位相の割り当てが存在する」という定理は、 論文自身が「2本目の接続・曲率・コホモロジー的整合性の、有限巡回群における対応物」と位置づけているものです。

ただし完全な復元ではありません。測っている対象が違うためです。 コバウンダリは重なり合う窓どうしの解釈の不一致、 ホロノミーは文脈を一周したときに位相が戻らない度合い。 前者を後者が代替できているかは、依然として自明ではありません。

② 3,000次元という下限 — 2本目でも3本目でも触れられていない

累積エネルギー解析による次元削減は、1本目で「核心的貢献」と位置づけられていました。 しかし2本目では言及されず、3本目でも復活していません。計算量の議論は疎グラフ・Chebyshev 近似（2本目）、 表引きと局所窓（3本目）へ移っています。

なお1本目のこの数値（累積エネルギー 82〜88%）は 1/f モデルからの理論的導出であって実測ではありません。 既存モデルの埋め込みを解析するだけで検証できるため、 3本の主張の中でもっとも安価に確かめられる部分でもあります。

③ 量子アルゴリズム — 意図的に捨てられた

2本目の中心だった QFT・位相推定・Oracle・振幅増幅は、3本目ではすべて取り除かれています。 これは失念ではなく判断です。2本目の検証で RQ5（量子優位性）が反証候補となり、 量子回路シミュレーションが総合コストで古典近似に及ばなかったことが背景にあります。

3本目は投稿カテゴリからも quant-ph を外し、「量子ハードウェアを必要としない古典有限群版」であることを明示しています。 2本目の量子部分は、3本目では継承されるのではなく、置き換えられたと読むのが正確です。

⚠ 読むときの注意

3本が並んで公開されている以上、読み手には「後続が前作を置き換えたのか、補完しているのか」が判別しづらい状態です。 現時点で正確な理解は、「後続はいずれも前作の一部を数学的に作り直したものであり、全部ではない」となります。

コホモロジー正則化と次元削減の主張については1本目を、量子スペクトル選択と実測結果については2本目を、 直接参照する必要があります。3本目だけを読んで全体像が得られるわけではありません。
