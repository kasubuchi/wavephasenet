なぜ QuantumPhaseNet になったのか

同じ著者による前稿と後継です。着想は引き継がれていますが、数学の舞台が入れ替わりました。 何が変わり、何が変わらなかったのか。そして何が引き継がれなかったのかを整理します。

01 // TIMELINE

半年で起きたこと

2026.01.12
WavePhaseNet
ハルシネーションを「非凸な真値集合と凸な \(L^p\) 空間のミスマッチ」として定式化。 離散フーリエ変換で埋め込み空間に意味的概念階層を構築し、コホモロジー正則化で局所の矛盾を制御する枠組みを提示。 実験は行われていない。
2026.07.23
QuantumPhaseNet（初稿）
位相を局所基底に依存しない量へ再定義。多様体・複素ベクトル束・接続という舞台へ移し、 量子スペクトル選択と幾何リスクを導入。この時点ではまだ理論のみ。
2026.07.30
QuantumPhaseNet（arXiv:2608.15820）
検証スタジオによる試作実験を追加。RQ1〜RQ4 が支持され、RQ5（量子優位性）は反証候補となった。 タイトルにも with Prototype Validation が加わっている。

前稿から後継への移行は、機能追加ではありません。 同じ直観を、より壊れにくい数学の上に置き直す作業でした。 その動機を理解するには、前稿が抱えていた弱点を見る必要があります。

02 // SHARED

変わらなかった5つの土台

舞台は変わりましたが、根っこの発想は一貫しています。

問題の立て方

幻覚は学習不足ではなく、表現空間の構造から生じる。だからデータではなく空間を作り直す。この診断と処方は両論文に共通します。

周波数と意味の対応

ゆっくり変化する成分が文書全体の意図、速く変化する成分が局所的な表現。この見立てが両論文の中心にあります。

位相を捨てない

どちらも FNet を「虚部を捨てるため共参照や文脈依存に弱い」と批判します。名前に Phase が入る理由です。

Transformer を置き換えない

補正項と残差として差し込む設計。係数をゼロにすれば元のモデルに厳密に戻ります。段階的に載せて、効かなければ外せます。

外付け知識への不信

シソーラス・オントロジーは埋め込み空間に直接入らず、RAG は外部依存が強く拡張性に乏しい。だから階層は空間の内側に作る — この立場も共通です。

04 // CORE

技術的に本質的な変更は2つ

表の項目は多いですが、根にあるのは次の2点です。他はここから派生しています。

① 位相を、座標から不変量へ

WAVEPHASENET

2語の噛み合いを位相角の差で測ります。 しかし \(\Phi_k\) は基底の取り方に依存する座標です。

\(\cos(\varphi_i - \varphi_j)\) という式は、暗黙に 「全ての語に共通の基準軸がある」と仮定してしまっています。

→
QUANTUMPHASENET

接続による平行移動を挟んでから内積をとります。 基準軸を決めなくても、2点間の整合性を比較できます。

局所ゲージ変換の下で値が変わらないことが、定理として示されています。

共変位相速度と共変整合性 \[ \Omega_\gamma(t) = \operatorname{Im}\big\langle \hat\psi,\, D_t\hat\psi \big\rangle, \qquad C^{\nabla}_{ij} = \operatorname{Re}\big\langle \hat\psi_i,\ P^{\nabla}_{j\to i}\hat\psi_j \big\rangle \]

代償もあります。平行移動は経路に依存するため、最短測地線か、文章順序に沿う経路か、 学習された参照経路か、いずれかを固定する必要が生じました。 前稿にはなかった選択肢であり、実装上の判断項目が1つ増えています。

② 直線から、任意のグラフへ

WAVEPHASENET

DFT は「トークンが等間隔に一列に並んでいる」ことを前提とします。

係り受け、共参照、検索根拠といった系列以外の関係は、 この枠組みでは扱えません。

→
QUANTUMPHASENET

グラフ Laplacian の低固有モードに置き換えることで、 任意の接続構造の上で同じ低周波抽出ができます。

辺集合には causal 近傍・k近傍・構文依存辺・共参照辺・検索根拠辺を混ぜられます。

実務的な影響はこちらの方が大きいかもしれません。 文書は本来、一列に並んだトークン列ではなく参照関係のネットワークだからです。 なお、この一般化には接続 Laplacian という拡張も用意されており、 各点の接空間にベクトルを留めたまま滑らかさを測れます。

05 // CONTINUITY

引き継がれなかった2つの主張

後継が前稿を完全に包含しているわけではありません。 前稿の主要な主張のうち2つは、後継に登場しません。

① コホモロジーと Hodge 分解

前稿の中核だった「窓被覆・コチェイン・コバウンダリ・調和射影による意味の貼り合わせ」は、 後継ではほぼ姿を消しています。局所の食い違いを測る役割は、曲率と幾何リスクに置き換わりました。

ただし両者は測っている対象が異なります。 コバウンダリは重なり合う窓どうしの解釈の不一致、 曲率は文脈を一周したときに意味状態が戻らない度合いです。 前者を後者が代替できているかは自明ではありません。

② 3,000次元という下限

累積エネルギー解析による次元削減は、前稿で「核心的貢献」と位置づけられていました。 しかし後継では言及されません。計算量の議論は疎グラフ・Lanczos・Chebyshev 近似へ移っています。

なお前稿のこの数値（累積エネルギー 82〜88%）は 1/f モデルからの理論的導出であって実測ではありません。 既存モデルの埋め込みを解析するだけで検証できるため、 両論文の主張の中でもっとも安価に確かめられる部分でもあります。

⚠ 読むときの注意

意図的な取捨選択であれば問題ありません。ただ、2本が並んで公開されている以上、 読み手には「後継が前稿を置き換えたのか、補完しているのか」が判別しづらい状態です。

現時点で正確な理解は、「後継は前稿の一部を数学的に作り直したものであり、全部ではない」となります。 コホモロジー正則化と次元削減の主張については、前稿を直接参照する必要があります。
