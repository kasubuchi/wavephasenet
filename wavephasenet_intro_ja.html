3分でわかる WavePhaseNet

AIの幻覚は、学習不足ではなく
数学の構造から必ず起きる。

WavePhaseNet は、LLM のハルシネーションを「データを増やせば直る問題」ではなく 表現空間の形が原因で必ず起きる現象として定式化し、 フーリエ変換によって埋め込み空間に意味の階層構造を直接埋め込むことで抑制を図る枠組みです。

Kiyotaka Kasubuchi & Kazuo Fukiya ／ 2026年1月12日 ／ arXiv:2602.14419
SCROLL
01 // ISSUE

なぜ、データを増やしても幻覚が消えないのか

多くの現場では「学習データが足りない」「プロンプトが悪い」と考えます。 この論文の出発点は、それでは説明がつかないという指摘です。

📊

平均的にもっともらしい

LLM が最適化しているのは「確率分布の上での平均的な良さ」であって、一つ一つの主張の正しさではありません。

🧩

局所は正しいのに全体が矛盾

各段落は筋が通っているのに、文書全体では前半と後半が食い違う。局所推論の整合性を保つ仕組みがありません。

🎚️

プロンプト職人芸への依存

複雑な推論をさせるには利用者側に高度なプロンプト設計スキルが要る。属人化して組織で使えません。

根本原因：形が合っていない

論文の核心はここです。「本当に正しいことの集合」と「AIが扱える表現空間」は、そもそも形が違う。

真実の集合

  • でこぼこしていて、飛び地がある（非凸）
  • 2つの正しい主張を混ぜても、正しい主張にはならない
  • 例：「A社は黒字」と「B社は赤字」を平均しても意味を成さない

AIの表現空間

  • なめらかで、隙間なく詰まっている（線形・凸）
  • 2点を混ぜた中間点が必ず存在してしまう
  • その中間点が「実在しない主張」になる

でこぼこな正解集合を、なめらかな空間で近似する。この形のミスマッチがある限り、 学習量をいくら増やしても「存在しない主張」は生まれ続けます。 だからこの論文は、データではなく空間の作り直しを提案します。

02 // IDEA

文章を「波」として分解する

WavePhaseNet の道具は3つです。いずれも信号処理では枯れた技術で、新しいのは それを意味に対して使うという点にあります。

01
DISCRETE FOURIER TRANSFORM

周波数分解 ＝ 意味のイコライザー

文章を単語の並びとしてではなく、波の重ね合わせとして見ます。 ゆっくり変化する成分（低周波）には文書全体のテーマや意図が、 速く変化する成分（高周波）には語順や言い回しの違いが乗ります。

たとえるなら音楽のイコライザーです。 同じ曲でも低音を上げれば土台が、高音を上げれば細部が際立ちます。 文章にも同じ帯域構造があり、DFT はそのつまみを与えます。
02
SEMANTIC CONCEPTUAL HIERARCHY STRUCTURE

SCHS ＝ 意味の階層を空間そのものに刻む

シソーラスやオントロジーのような「外付けの辞書」は、埋め込み空間の中に直接は入りません。 RAG も外部依存が強く拡張性に乏しい。そこで 周波数帯域そのものを階層として使い、意味の上下関係を空間の内側に作ります。

効果として狙うのは、プロンプト職人芸からの脱却です。 階層が空間側にあれば、利用者が高度な指示文を書かなくても、 モデルが自分で「いまどの粒度の話をしているか」を扱えます。
03
COHOMOLOGY REGULARIZATION

コホモロジー正則化 ＝ 証言の突き合わせ

文書を重なり合う小窓に分け、各窓が出した解釈を持ち寄ります。 重なった部分で解釈が食い違っていれば、その食い違いの総量を損失として測り、 学習で減らします。矛盾のない解釈だけが残る成分を、数学的に取り出せます。

たとえるなら複数の目撃証言の突き合わせです。 証言が重なる場面で食い違いがあれば、そこが怪しい。 全員の証言が矛盾なく重なる部分（調和成分）を抽出するのが Hodge 理論の役割です。
03 // HOW

1つの文章が処理される流れ

1
埋め込み
トークン列を埋め込み行列に変換（系列長 N × 次元 d）
2
FFT で周波数に変換
系列方向に高速フーリエ変換。計算コストは軽く、系列長に対してほぼ線形
3
帯域を分ける
低周波（意図）・中周波（談話構造）・高周波（表現）に多段分離
4
低周波を意図ベクトルとして固定
文書全体が向かう方向を取り出し、生成中ずっと参照し続ける
5
高周波を意図に条件づけて生成
言い回しや語順は、固定された意図と矛盾しない範囲で生成する
6
逆変換して文章に戻す
逆DFTで元の形式に復元。数学的に完全復元でき、情報は失われない
7
窓ごとの解釈の食い違いを罰する
重なり合う窓の間の矛盾を損失に加え、学習で整合性を高める

重要なのは、これが既存のTransformerを置き換えるものではないことです。 各層・各ヘッドにスペクトルモジュールと正則化項を差し込む形で実装でき、 低周波の意図は残差としてAttentionの入力に足されます。

04 // EVIDENCE

主張の中身

自然言語は Zipf 則に従い、自己相似的な構造を持ちます。そのため埋め込みのエネルギーは 低周波に偏って分布し、高周波側では 1/f 型に減衰します。 低い方から順に足し上げていくと、約3,000次元で全体の82〜88%に達する。 これが「意味と意図を保存する下限」だ、というのが論文の中心的な主張です。

これを下回ると、意味的に似た文と、単に構文的に似ているだけの文を区別できなくなるとされます。 裏を返せば、24,576次元のうち大半は冗長であり、8分の1に落としても厳密な推論は可能だという主張になります。

⚠ この数値の位置づけを誤解しないでください
  • 82〜88% という値は実測ではなく、1/fモデルからの理論的導出です。実際の GPT-4 埋め込みを解析した結果ではありません。
  • この論文には評価実験、ベンチマーク比較、アブレーション研究のいずれも含まれていません。提案されているのは枠組みと検証方法です。
  • したがって「導入すれば幻覚が○%減る」と言える段階ではありません。実データでの検証が次の課題として明示されています。
  • 後続の QuantumPhaseNet では、同じ着想を書き直したうえで試作機による実測が行われています。
05 // WHY FOURIER

「フーリエ変換を使う」だけでは足りない

Attention をフーリエ変換に置き換える研究は既にあります（FNet）。 では何が違うのか。ここが本提案の分かれ目です。

FNet のやりかた

  • Attention をフーリエ変換で置き換えて高速化する
  • 複素数の虚部を捨てる（実部だけ使う）
  • 結果として、共参照関係や文脈依存の処理が弱くなる

WavePhaseNet のやりかた

  • 速度ではなく意味操作のために変換する
  • 位相を保持する（名前の Phase はここから）
  • 帯域ごとに意味演算子を差し込み、階層を明示的に操作する

可逆な変換それ自体には価値がありません。変換した先で何を操作するかに価値があります。 周波数側に移してから帯域ごとの重みを変え、また戻す。この往復の間に挟む操作が本体です。 たとえば「全体テーマは保持」「言い回しは減衰」「特定の対比構造は除去」といった操作を、 線形代数の演算として厳密に書けるようになります。

06 // USE CASES

どんな業務に効くか

長い文書を、筋を通したまま扱う必要がある業務ほど効果が見込めます。

長文レポートの生成

調査報告書や技術報告書。低周波の意図を固定することで、後半で当初の目的から逸れる問題に対処します。

→ 低周波＝意図を生成中ずっと参照

複数文書の突き合わせ

仕様書と実装、契約書と運用実態など、重なり合う情報源の間の矛盾を検出したい場面。

→ コホモロジー正則化が食い違いを定量化

推論コストの削減

次元を 24,576 から 3,000 に落とせるなら、メモリと計算コストが大幅に下がります。

→ 累積エネルギー解析による理論的裏づけ

エッジ・組込みでの推論

論文が「致命的」と指摘するのがこの領域。厳密さが要求され、かつ計算資源が限られます。

→ 低次元化と厳密性を両立させる設計

要約・意図抽出

文書全体のテーマを1本のベクトルとして取り出せるため、要約や分類の前処理に使えます。

→ 大域意図ベクトル g として直接取得

プロンプト依存からの脱却

意味階層を空間側に持たせることで、利用者側の指示文設計スキルへの依存を下げます。

→ SCHS を埋め込み空間の内側に構築
07 // SCOPE

できること／できないこと

数学的に示されていること

  • DFT は可逆であり、逆変換で元の埋め込みを完全に復元できる
  • 共役対称性により、実数値での復元が保証される（高周波は半分だけ学習すればよい）
  • Laplacian の零空間が「矛盾なく貼り合わせられる成分」に対応する
  • FFT・疎行列・反復解法により、計算量の面でスケールする

まだ確かめられていないこと

  • 実データでの有効性（ベンチマーク評価が未実施）
  • 3,000次元という下限が、実際の GPT-4 埋め込みでも成り立つか
  • 「低周波＝正しい意図」が、あらゆる文書で成り立つか
  • λ・μ・η 各項の寄与（アブレーション研究が未実施）
⚠ 幻覚はゼロになりません
  • 論文自身が、より高次のコホモロジーに由来する本質的な障害は残ると明記しています。射影で消せるのは一部です。
  • 低周波が「正しい意図」を表す保証はありません。長く反復された誤情報も低周波成分になり得ます。
  • そもそも真値集合が非凸である以上、線形な表現空間で完全に一致させることは原理的にできません。狙いは抑制であって撲滅ではありません。
  • 高リスク業務では、AIの出力を単独の判断根拠にせず、人の確認と出典提示を組み込んでください。
08 // ADOPTION

導入するなら、この順番で

論文は実装を Transformer への差し込みとして設計しています。 検証しやすい順に並べると次のようになります。

段階やることこの段階で分かること
1埋め込みのスペクトルを実測自社データで本当に 1/f 構造が出るか
2累積エネルギーを計算何次元で何%になるか（3,000は妥当か）
3次元削減して精度を比較削っても性能が落ちないか
4スペクトルモジュールを差し込む低周波の意図注入が長文生成に効くか
5コホモロジー正則化を追加局所の矛盾が実際に減るか（最重要）
6λ・μ・η のアブレーションどの項が効いているかの切り分け

段階1〜2 は既存モデルの埋め込みを解析するだけで、モデルの改造は不要です。 論文の中心的主張が自社データで成り立つかを、最小コストで確認できます。 ここが崩れるようなら先に進む意味はありません。

09 // FAQ

よくある質問

既存のLLMを置き換えることになりますか？

置き換えではありません。各層・各ヘッドにスペクトルモジュールと正則化項を差し込む設計です。低周波の意図は残差としてAttentionの入力に加算されます。

RAGを導入済みですが、不要になりますか？

論文はRAGについて「外部依存が強く拡張性に乏しい」と指摘し、意味階層を埋め込み空間の内側に持たせる方向を提案しています。ただしRAGを置き換えるという主張ではなく、外部知識の参照とは別の層の話です。

計算コストは増えますか？

FFT は系列長に対してほぼ線形で軽量です。Laplacian も疎行列なので反復解法で扱えます。むしろ次元削減が効けば全体としては下がる可能性があります。

幻覚はどれくらい減りますか？

この論文には実験結果がないため、定量的にはお答えできません。示されているのは理論的枠組みと、評価すべき指標（perplexity、局所整合率、Zipf偏差）です。まずは自社データでの検証が必要です。

QuantumPhaseNet とはどういう関係ですか？

WavePhaseNet が前稿、QuantumPhaseNet が後継です。後継では同じ着想を「ゲージ共変」な枠組みへ書き直し、位相を座標に依存しない量として定義し直しています。また試作機による実測が加わっています。

実験がないのに提案する意味はありますか？

この論文の主眼は「幻覚がなぜ構造的に不可避なのか」を数学的に定式化することにあります。原因の定式化が先にあり、対策の実証は後続研究に委ねられる、という構成です。実際に後継論文で実測が行われています。
